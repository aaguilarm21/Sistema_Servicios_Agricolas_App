Diagrama ER - Base de Datos
Proyecto: Sistema_Servicios_Agricolas
Última actualización: 2026-08-08

==============================================================
ENTIDADES DEL SISTEMA
==============================================================

1) Usuario  [auth.User — modelo integrado de Django]
   - id              (PK, autoincremental)
   - username        (nombre de usuario, único)
   - password        (contraseña)
   - first_name      (nombre)
   - last_name       (apellido)
   - email           (correo electrónico)
   - is_active       (activo)
   - is_superuser    (superusuario)
   - date_joined     (fecha de registro)
   - ... (otros campos estándar de auth.User)

--------------------------------------------------------------

2) PerfilUsuario  [UserProfile]
   - id              (PK, autoincremental)
   - usuario         (FK → Usuario, OneToOne, CASCADE)   [Relación 1:1]
   - codigo          (CharField, max=50, único)
   - puesto          (CharField, max=150)
   - created_at      (DateTimeField, auto)
   - updated_at      (DateTimeField, auto)

--------------------------------------------------------------

3) Proveedor
   - id                  (PK, autoincremental)
   - codigo              (CharField, max=50, único)
   - nit                 (CharField, max=20)
   - razon_social        (CharField, max=200)
   - nombre_propietario  (CharField, max=150)
   - regimen_tributario  (CharField, max=100)
   - tipo_factura        (CharField, max=100)
   - dias_credito        (IntegerField, default=0)
   - created_at          (DateTimeField, auto)
   - updated_at          (DateTimeField, auto)

--------------------------------------------------------------

4) Empleado
   - id              (PK, autoincremental)
   - empresa         (CharField, max=200)
   - empleado        (CharField, max=150)
   - no_cui          (CharField, max=20)
   - puesto          (CharField, max=100)
   - nombre_puesto   (CharField, max=150)
   - created_at      (DateTimeField, auto)
   - updated_at      (DateTimeField, auto)

--------------------------------------------------------------

5) Maquinaria

   - codigo_maquina  (CharField, max=50, único)

   - marca_maquina   (CharField, max=150)
   - serie_maquina   (CharField, max=150)
   - placa_matricula (CharField, max=50)
   - observaciones   (TextField, nullable)
   - created_at      (DateTimeField, auto)
   - updated_at      (DateTimeField, auto)

--------------------------------------------------------------

6) Bodega
   - id              (PK, autoincremental)
   - codigo          (CharField, max=50, único)
   - nombre_bodega   (CharField, max=200)
   - unidad_medida   (CharField, max=50)
   - capacidad       (CharField, max=50)
   - observaciones   (TextField, nullable)
   - created_at      (DateTimeField, auto)
   - updated_at      (DateTimeField, auto)

--------------------------------------------------------------

7) Articulo
   - id              (PK, autoincremental)
   - codigo_articulo (CharField, max=50, único)
   - descripcion     (CharField, max=250)
   - unidad_medida   (CharField, max=50)
   - categoria       (CharField, max=100)
   - stock           (DecimalField, 10,2, default=0)
   - created_at      (DateTimeField, auto)
   - updated_at      (DateTimeField, auto)

==============================================================
ENTIDAD PRINCIPAL DE TRANSACCIONES
==============================================================

16) RegistroOperativo
    - id                (PK, autoincremental)
    - no_boleta         (CharField, max=100)
    - fecha_labor       (DateField)
    - tipo_servicio     (CharField, max=100)
    - proveedor         (CharField, max=200)            -- texto, NO es FK
    - codigo_maquina    (CharField, max=100, nullable)  -- texto, NO es FK
    - placa             (CharField, max=100, nullable)
    - operador          (CharField, max=200, nullable)
    - finca             (CharField, max=200)
    - lote              (CharField, max=200)            -- Caña / Lote
    - area_lote         (DecimalField, 10,2, nullable)  -- en hectáreas
    - actividad         (CharField, max=200, nullable)
    - labor             (CharField, max=200, nullable)  -- puede mapear a Labor.codigo
    - corte_semilla     (CharField, max=20,  nullable)  -- Lote Corte Semilla
    - unidades          (DecimalField, 12,2, nullable)
    - horometro_inicial (DecimalField, 12,2, nullable)
    - horometro_final   (DecimalField, 12,2, nullable)
    - costo_unitario    (DecimalField, 12,2, nullable)
    - num_factura       (CharField, max=100, nullable)
    - cuenta_contable   (CharField, max=150, nullable)  -- puede mapear a Cuenta.codigo
    - variedad          (CharField, max=150, nullable)  -- puede mapear a Variedad.codigo
    - total_paquetes    (DecimalField, 12,2, nullable)  -- Total Paq/Cajas
    - peso_kg           (DecimalField, 12,2, nullable)
    - caporal_01        (CharField, max=150, nullable)
    - caporal_02        (CharField, max=150, nullable)
    - mayordomo         (CharField, max=150, nullable)
    - administrador     (CharField, max=150, nullable)
    - lugar_origen      (CharField, max=200, nullable)
    - lugar_destino     (CharField, max=200, nullable)
    - observaciones     (TextField, nullable)
    - created_at        (DateTimeField, auto)

==============================================================
RELACIONES
==============================================================

  Usuario (auth.User) ──(1:1)── PerfilUsuario
    └─ UserProfile.usuario → User.id  (OneToOneField, CASCADE)

  [Las demás entidades son independientes entre sí.
   RegistroOperativo almacena referencias a Proveedor,
   Maquinaria, Labor, Cuenta y Variedad como texto (CharFields),
   sin claves foráneas formales.]

==============================================================
ROLES / GRUPOS DE DJANGO  (no son modelos propios)
==============================================================

  - Admin    → acceso total (gestión de usuarios, edición, eliminación)
  - Usuario  → acceso operativo (crear/ver registros, reportes)

==============================================================
NOTAS
==============================================================

  * id_proveedor en Maquinaria: texto sin FK formal a Proveedor.
  * proveedor en RegistroOperativo: texto libre (nombre/razón social),
    sin FK formal a la tabla Proveedor.
  * codigo_maquina en RegistroOperativo: texto que puede coincidir
    con Maquinaria.codigo_maquina, sin FK formal.
  * Auxiliar con tipo='finca' actúa como catálogo de fincas
    para los registros operativos.
